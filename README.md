# GrantKros-CoopMonitor
To develop / modify existing hardware for a product that monitors and controls opening and closing of a Chicken Coop thus eliminating the need for manual operations. The product is battery powered and utilizes RTC (Real Time Clock) in order to keep track of time and open / close the door automatically at set time. The firmware Logic development is also scope of product.
